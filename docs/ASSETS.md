# Ассеты и лицензии

- `public/images/hoi-an.jpg`: AI-generated concept art, создано для этого проекта. Не документальная фотография и не этнографически проверенный референс. Дополнительного скачанного фото-контента нет.
- `public/favicon.svg`: собственный SVG фонаря.
- 3D сцены: процедурная геометрия, код в `World.tsx`; сторонних GLB нет.
- Golos Text, Manrope: пакеты @fontsource, OFL; тексты лицензий поставляются в node_modules соответствующих пакетов. Шрифты отдаются с того же origin.
- Lucide: ISC; Babylon.js: Apache-2.0; React: MIT. Полные версии/лицензии зависимостей — package-lock и их npm-пакеты.
- Музыка, озвучка, анимационные риги и финальные портреты не добавлены.
