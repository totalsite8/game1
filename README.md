# Маршрут без фильтра

**Катя и Оля во Вьетнаме** — web-first narrative adventure. Сейчас это **играбельный прототип 0.1**, а не весь объём игры из брифа.

## Для новой сессии

Сначала прочитайте **[PROJECT_STATE.md](PROJECT_STATE.md)** — фактическое состояние, проверки, ограничения и следующий шаг. Исходные требования: [GAME_BRIEF_KATYA_OLYA_VIETNAM_RU.md](GAME_BRIEF_KATYA_OLYA_VIETNAM_RU.md). Архитектура: [docs/ADR-001.md](docs/ADR-001.md).

## Запуск

Node.js 22.12+ (22 LTS), npm. Версии зафиксированы в lockfile.

```sh
npm ci
npm run dev                 # 0.0.0.0:5173
npm test                    # core, все достижимые ветки, HMAC
npm run build               # TypeScript + Vite + versioned offline cache
npm run preview             # 0.0.0.0:4173, production assets + API middleware
npm run format:check
```

Браузерные тесты на Linux (в отдельном терминале должен работать dev/preview):

```sh
node scripts/browser-libs.mjs
TEST_URL=http://localhost:5173 LD_LIBRARY_PATH=/tmp/route-browser-libs/lib npm run test:e2e
```

Для тестирования применяется Chromium из npm-пакета `@sparticuz/chromium`. Продукт от него не зависит. Playwright-тесты — не замена реальным iOS/Android-устройствам.

## Что можно попробовать

- Начать эпизод «Карта без адреса», выбрать Катю или Олю.
- 3 процедурные Babylon.js-локации: двор, рынок, набережная; каждый персонаж — процедурная фигура сo своей внешностью, походкой и позой.
- Tap-to-move, WASD/стрелки, перетаскивание камеры, касание NPC или кнопка «Поговорить».
- 12 решений, 4 исхода, дневник наблюдений и непроверенных версий.
- Автосохранение в IndexedDB; экспорт/импорт и удаление.
- RU/EN; текстовый режим без WebGL, крупный текст и мягкий пересказ.
- PWA/offline после успешной первой загрузки production-сборки.

Переключение героини меняет внешность, походку и позу управляемой фигуры, но пока не меняет ветки сюжета и способности. Время, бюджет и батарея показывают последствия выборов; их нулевые значения ещё не запускают отдельные recovery-сцены. Карта показывает последовательность, а не свободное перемещение между актами.

## Публикация

[Инструкция Vercel](docs/DEPLOYMENT.md). Рабочая ветка: `arena/01a1030b-game1`.

Конфигурация Vercel и функции созданы. **Деплой не выполнен: Vercel CLI не авторизован**, а временный деплой был отклонён сервисом. GitHub-аутентификация не предоставляет доступа к Vercel.

Облако не имитируется: `/api/saves/sync` отвечает `503`, пока нет постоянной БД и серверных сессий. Telegram HMAC helper покрыт тестами, но полноценные Mini App, бот и авторизация ещё не подключены. URL `/telegram` открывает тот же гостевой клиент.

## Поддержка до 2030

Никакая библиотека не гарантирует вечную совместимость. Основа рассчитана на сопровождение: независимый core, данные отдельно от 3D, версионированные локальные сохранения, локальные шрифты, ленивый renderer, текстовый fallback, тесты и Dependabot. Для реальной поддержки нужны регулярные обновления и device QA.
